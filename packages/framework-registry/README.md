# @mr.dj2u/framework-registry

Browser-safe shared typed framework registry, template catalog, plan contracts, and execution identities for iSquared and Mr. DJ's Dev Suite (MDS).

## Features

- **Browser-Safe**: Pure TypeScript with zero Node.js runtime imports.
- **Default Exact**: Expo Exact is the primary default framework (`isDefault: true`).
- **Expo React Native**: Maintained as an explicit, backwards-compatible framework option.
- **Template Catalog**: Pinned upstream templates (blank, chat, landscapes, softwear) with immutable git revisions.
- **Plan & Approval Contracts**: Deterministic plan generation, canonical JSON hashing, and approved plan digest verification.
- **Structured Errors & Events**: Standardized error taxonomy and progress reporting with cancellation support.
- **Discovery Engine Types**: Requirements discovery contracts for Jenny, the project creation agent.
