# Mr. DJ's Dev Suite Style

## Visual Direction

This file is only for the look and feel of the dev suite and generated MDS
project materials. Technical rules live in `project/guidelines.md`.

- Quiet, practical, developer-first interfaces.
- Clear hierarchy, compact information density, and readable contrast.
- Warm but not noisy language in docs and CLI output.
- Prefer restrained color, direct labels, and predictable layouts over decorative
  flourish.
- Use examples that feel like real Expo project work, not marketing filler.

## Generated App Defaults

- Generated project docs should feel useful on first read, with concise prompts
  and concrete next steps.
- `project/style.md` in generated apps should focus on colors, typography,
  spacing, icon direction, motion tone, visual references, and brand mood.
- Keep technical guidance out of style files; put it in
  `project/guidelines.md`.
